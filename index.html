Follow the four paths below. The detailed pages and Markdown references stay focused on one job each, so the same technical facts do not need to be maintained in multiple places.

1. Understand the contest

Rules, rounds, scoring context, supplied parts, bot constraints, and the balloon-defense challenge.

2. Build the bot

Wire the boards, servos, sensors, battery, and LiDAR safely, then use the Board UI to check the result.

3. Code the controller

Connect to Wi-Fi, register with the screen token, maintain the heartbeat, and send your first command.

4. Use the AI Markdown set

Give an AI coding agent the checklist, UDP client pattern, service map, capabilities, and wiring references.
